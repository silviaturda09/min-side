# FilmFinder: navnet på prosjektet_

## Om prosjektet

**Tema:** 
Film club
**Hvem er sida for?** 
Siden er for personer som nyter filmer, bruker tiden på mange forskjellige typer av filmer og har favorittskuespiller.
**Hva kan brukeren gjøre på sida?** 
Brukeren kan søke etter filmer, filtrere filmer etter år og sjanger, gi filmer en score fra 1 til 6 og skrive en anemldelse.
